# PhotoBox — техническое задание

Галерея фото и видео для Android. Работает с файлами и папками напрямую, без
медиатеки системы (MediaStore).

Пункты с `+` в начале уже сделаны.

## Платформа

- + Kotlin + Jetpack Compose, пакет `xx.photobox`, minSdk 30, targetSdk 36.
  Сборки под arm64-v8a, armeabi-v7a и x86_64.
- + Языки: en, ru, uk.
- + Доступ к файлам через «All files access» (`MANAGE_EXTERNAL_STORAGE`),
  чтение и запись через `java.io.File`. Обход томов (внутренняя память, SD-карта)
  выполняет само приложение.
- + Основа взята из шаблона `000-ARCHIVE/XXX`: скрипты сборки, updater, About,
  настройки «как везде», меню ⋮ в правом верхнем углу.
- + Код из SnapSort копируется и дорабатывается здесь, общих модулей с ним нет.
- + Интерфейс всегда в естественной ориентации устройства (`nosensor`: портрет
  на телефоне, ландшафт на TV-приставке). Фото, видео и слайд-шоу поворачиваются
  сами, как задано в настройках.

## Экраны

+ При запуске открываются **миниатюры** последнего открытого альбома. При первом
запуске это `DCIM/Camera`, а если такой папки нет, то список альбомов.

### 1. Альбомы

- + Альбом — это папка, в которой непосредственно лежат фото или видео.
- + Альбомы ищутся внутри корней поиска, по умолчанию `DCIM` и `Pictures`.
  Корни добавляются через «+» → «Добавить папку поиска» и удаляются со своего
  заголовка в списке. Список разбит на разделы по корням.
- + Папка, в которой лежит музыка, — не альбом (обложки музыкальных альбомов),
  но её подпапки проверяются.
- + Строка альбома: обложка (самый новый файл), имя, количество файлов.
  Открытый альбом выделен инверсно, и список прокручен к нему.
- + Сортировка: по имени, дате, количеству.
- + Скрытые папки (имя начинается с точки или внутри есть `.nomedia`)
  показываются, только если это включено в настройках.
- + Кнопка «+» → «Новый альбом» спрашивает имя, создаёт папку в `Pictures/`
  (родительскую папку можно сменить) и сразу её открывает. То же делает
  «Новый альбом» в ⋮ заголовка корня, внутри этого корня. Совсем пустая папка
  (не сам корень) показывается в списке как пустой альбом с иконкой программы
  вместо обложки. Его ⋮ → «Удалить альбом» удаляет пустую папку.
  ⋮ любого альбома → «Переименовать» переименовывает его папку. Наполняется
  переносом или копированием из других альбомов.

### 2. Миниатюры альбома

- + Сетка от 2 до 5 колонок, меняется щипком (pinch). Число колонок запоминается.
- + Группировка по датам с заголовками дней.
- + Ползунок быстрого скролла с подписью даты.
- + Сортировка: по дате, имени, размеру.
- + Фильтр по имени и по диапазону дат: ⋮ → «Фильтр», строка под верхней
  панелью показывает условия и «N из M», ✕ снимает. Просмотр и слайд-шоу
  идут по отфильтрованным. При смене альбома фильтр сбрасывается.
- + Долгий тап включает выделение, дальнейшие тапы добавляют или снимают файлы.
  Действия над выделенными перечислены в разделе «Действия над файлами».
- + Тап по миниатюре открывает просмотр.

### 3. Просмотр

- + Полный экран, свайпом листаются файлы текущего альбома в порядке сетки.
- + Зум щипком и двойным тапом, перетаскивание при зуме.
- + Видео играет во встроенном плеере (Media3) или во внешнем приложении,
  выбирается в настройках.
- + Меню ⋮: «Сведения», «В корзину».

### 4. Слайд-шоу

- + Запускается из меню папки (⋮ на экране миниатюр альбома).
- + Показывает фото этого альбома от выбранного до последнего. Видео
  пропускаются. В конце показ останавливается: поверх последнего кадра
  иконка программы (без фона), панель управления открыта, «Пуск» начинает
  сначала. Запомненный кадр при досмотре до конца сбрасывается.
- + Смена кадров плавным наплывом (crossfade) по центру.
- + Время показа задаётся в настройках ползунком от 1 до 30 секунд,
  по умолчанию 5.
- + Тап показывает панель внизу: «Назад», «Сведения», «Пауза/Пуск», «Вперёд»;
  вверху стрелка выхода. Экран не гаснет во время показа.
- + Запоминается последний показанный кадр последнего альбома. При новом запуске
  спрашивается «Сначала» или «Продолжить». После паузы показ продолжается
  через 3 секунды.

### 5. Корзина

- + Своя, по одной на каждый том: `Documents/PhotoBox/.Trash` во внутренней
  памяти и на SD-карте. Перемещение в неё делается переименованием в пределах
  того же тома: это мгновенно и не требует места.
- + Файл хранится под именем `<время удаления>.<расширение>`, рядом лежит запись
  `<время>.path` с исходным путём. При восстановлении исходная папка создаётся
  заново, если её уже нет.
- + В корзине лежит `.nomedia`, чтобы другие галереи её не показывали.
- + Старые корзины `.PhotoTrash` в папках альбомов один раз переносятся в новую.
- + Экран корзины: сводка «N файлов · размер», строки с именем, исходной папкой,
  временем удаления и размером. Тап открывает файл на весь экран. У строки своё
  меню: «Восстановить», «Удалить навсегда». На панели: «Восстановить всё»,
  «Очистить», с прогрессом.
- + Автоочистка: файлы старше N дней удаляются при запуске. N задаётся
  в настройках (7, 14, 30, 60 или 90), по умолчанию 30.

### 6. Настройки

- + Тема (системная, светлая, тёмная), акцент из палитры, язык, проверка
  обновлений при запуске — как в остальных приложениях.
- + Показ скрытых папок.
- + Плеер видео: встроенный или внешний.
- + Время слайда в слайд-шоу.
- + Поворот фото, видео и слайд-шоу: по датчику, как в системе, никогда.
- + Срок хранения в корзине.
- + About открывается кнопкой (i) на экране настроек.

### Навигация

+ Один главный экран (миниатюры альбома), остальные экраны открываются из меню.
В левом верхнем углу кнопка ✕ (выход из приложения), в правом — ⋮ (меню).
Меню ⋮ содержит «Альбомы», «Корзину», «Сортировку», «Слайд-шоу» (в альбоме)
и «Настройки». Имя альбома в верхней панели нажимается и открывает список
альбомов.

## Действия над файлами

Для одного файла (из просмотра) и для выделенных (из сетки):

- + Удалить в корзину (из просмотра).
- + Удалить в корзину (выделенные).
- + Поделиться (`ACTION_SEND` / `ACTION_SEND_MULTIPLE` через FileProvider).
- + Повернуть на 90° без потерь: меняется только ориентация в EXIF
  (JPEG, PNG, WebP).
- + Переименовать (только один файл).
- + Переместить или скопировать в папку, выбранную в собственном браузере папок;
  в нём есть «Новая папка».
- + Информация: имя, путь, размер, разрешение, дата съёмки, камера, параметры
  съёмки из EXIF, координаты. Тап по координатам открывает карту через `geo:`.

+ Вместе с фото переносятся и удаляются RAW-файлы, лежащие рядом под тем же
именем (как в SnapSort).

## Интеграция с другими приложениями

- `ACTION_VIEW` для `image/*` и `video/*`: PhotoBox появляется в «Открыть
  с помощью» и показывает переданный файл.
- `GET_CONTENT` / `PICK` для `image/*` и `video/*`: PhotoBox открывается в режиме
  выбора и возвращает выбранный файл или несколько файлов через FileProvider.

## Даты

- + Дата файла — это дата съёмки из EXIF, а если её нет, дата изменения файла.
- + Даты кэшируются на диске по ключу «путь + mtime + размер», поэтому повторное
  открытие альбома не перечитывает EXIF.

## Не делаем

Облако, редактор, распознавание лиц, избранное, установку обоев, поиск,
MediaStore и системную корзину.
